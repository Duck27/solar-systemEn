# Solar System

Interactive 3D model of the Solar System with animated orbits, planet
information, and adjustable simulation speed.

**Live demo:** https://duck27.github.io/solar-systemEn/

## Features

- Explore the Sun, planets, Moon, and asteroid belt
- Open information cards by selecting celestial objects
- Change the simulation speed or reverse time
- Rotate, zoom, and navigate the scene with the mouse

## Built with

- [Three.js](https://threejs.org/)
- [GSAP](https://gsap.com/)
- [Vite](https://vite.dev/)

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.
